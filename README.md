# Learning HTML & CSS Practice Repository

This repository is a personal collection of mini practice exercises for learning and improving HTML and CSS skills. It contains small standalone web pages that demonstrate core front-end concepts, layout techniques, styling patterns, and page structure.

## Overview

The project is organized inside the `HTML-CSS_code` folder and includes practice files covering:

- HTML document structure and page elements
- Text formatting, lists, tables, and forms
- Links, images, backgrounds, and sprites
- CSS basics, selectors, and styling
- Internal, external, and multiple stylesheet usage
- Layout design with fixed and liquid widths
- Positioning, overflow, centering, and spacing
- HTML5 semantic layout structure
- Image and content styling techniques

## What I Practiced

This repo includes hands-on examples for a variety of front-end building blocks, including:

- semantic HTML structure
- CSS selectors and inheritance
- box model and spacing
- backgrounds and typography
- alignment and centering techniques
- navigation and link styling
- forms, tables, and lists
- responsive-style layout concepts
- image handling and rollover effects

## How to Use

1. Open any `.html` file in a browser.
2. For a smoother workflow, use a live preview extension or a local web server.
3. Open the related CSS file to see how the page is styled.
4. Experiment by modifying the markup or CSS to understand how changes affect the page.

## Notes

This is a learning repository intended for practice, experimentation, and reference. It is designed to help build confidence with HTML and CSS fundamentals while working through small, focused examples.

## Goal

The main purpose of this repo is to strengthen practical front-end development skills by creating simple, clean, and reusable web layouts and styling patterns.
